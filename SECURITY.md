# Security Policy

## Supported versions

ContextMaxxing is currently under active development. Only the latest version is supported.

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately using GitHub's security advisory feature rather than opening a public issue.

Please include enough information to reproduce and understand the issue.

## Scope

ContextMaxxing is a static satirical marketing site. It has no backend, authentication system, database, or user data. Nothing is stored, collected, or processed.

Security issues affecting visitors, such as cross-site scripting, injection vulnerabilities, exposed secrets, or vulnerable dependencies, are in scope.

Fictional product behavior, fictional metrics, and the absence of the advertised platform are not security vulnerabilities.

## Response

Valid reports will be reviewed as time permits. Reports are currently reviewed by a human. There is no bug bounty program.

## Safe harbor

Good-faith security research is welcome. Please avoid disruptive testing against the production deployment.
